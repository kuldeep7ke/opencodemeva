How it works

1
Install the patch

Run the setup wizard and it copies the pack into ~/.config/opencode, without touching anything else.

2
Run opencode

Just restart your terminal and start opencode as usual. No new accounts, no cloud service.

3
Use your new team

Delegate to @planner, @code-reviewer, @security-reviewer, load skills, and run slash commands.
